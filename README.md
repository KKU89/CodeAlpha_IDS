# CodeAlpha Intrusion Detection System (IDS)

A Python-based network monitoring tool designed to detect malicious traffic and potential flood attacks in real time.

## Features
- Real-time packet sniffing using Scapy.
- Localhost loopback interface (`lo`) traffic analysis.
- Automated alert triggers for ICMP flood attacks.

## Setup & Usage
Ensure Scapy is installed on your environment.

```bash
sudo python3 ids.py
```
